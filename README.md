# ProgressIQ

**Track. Analyze. Improve.**

ProgressIQ is a full-stack fitness tracking web application that helps users monitor their workouts, personal records (PRs), nutrition, and overall fitness progress.

## Features

- User registration and login
- Workout tracking
- Personal Record (PR) tracking
- Calorie and protein tracking
- Weekly and monthly progress analytics
- Exercise library *(planned)*
- AI-powered workout and nutrition recommendations *(planned)*

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** MySQL
- **Version Control:** Git & GitHub
